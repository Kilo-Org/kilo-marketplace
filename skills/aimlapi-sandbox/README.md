# aimlapi-sandbox

Test integrations for free.

## Install

```bash
gh skill install aimlapi/skills aimlapi-sandbox
```

Or install every skill: see the [root README](https://github.com/aimlapi/skills#install).

## What it covers

- Three ways to switch sandbox on: model prefix, header, sandbox key
- Scenario markers for tool calls, JSON, long answers, errors, slow answers and failed jobs
- A script that sends any request in sandbox mode and shows the headers

The agent reads [SKILL.md](SKILL.md).

## Requirements

`AIMLAPI_API_KEY` (live or sandbox key).
