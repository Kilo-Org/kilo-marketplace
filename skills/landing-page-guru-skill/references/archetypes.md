# Four starting archetypes

Choose according to the visitor's decision, not a mandatory section count.

| Type | Primary decision | Content that usually helps | Operational check |
| --- | --- | --- | --- |
| Product waitlist | Is this relevant enough to hear about later? | Specific problem and mechanism, honest stage, sample product view, what signup means | No invented launch date or customer proof; honest endpoint status |
| B2B demo | Is a conversation worth my time? | Use case, credible product evidence, fit, expected demo, objections | Qualification fields justified; scheduling/delivery expectations verified |
| Local-service inquiry | Does this business serve my area and need? | Service area, scope, process, permissioned work examples, real contact options | Mobile input, service qualification, actual request destination |
| Basic lead magnet | Is the resource useful and worth the data requested? | Concrete contents, sample, intended audience, clear delivery promise | Resource exists, opens/downloads, and is delivered as described |

Use existing navigation if it supports the decision. One primary outcome does not
require hiding useful product, contact, or privacy information. Product-led proof
can replace testimonials when there is no customer evidence.

V1 does not promise a new ecommerce checkout, account onboarding system, multi-step
funnel engine, or nurture automation. When an existing page contains one, inspect
what is available and state the boundaries of verification. For a lead magnet,
produce a resource only if that content work is included in the user's request.
