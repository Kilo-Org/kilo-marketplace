# Social Case to Excel

A standalone English adaptation of the social research workflow published at https://github.com/lingling1989r/social-case-to-excel . It produces source-linked Excel case libraries, methods and illustrated learning documents.

This catalog copy contains workflow instructions only. The canonical repository holds the Python build and QA templates, schema and Chinese, English, Japanese and Korean README files. No scripts or preview binaries are imported into this catalog copy.

Requires a configured ClaudeBaby MCP connection. Available platforms and permissions must be checked before collecting records. Workbook generation requires openpyxl and Pillow. Historical examples and offline client tests do not establish live platform coverage or end-to-end Goose compatibility.

The original workflow was published under MIT-0 through ClawHub: https://clawhub.ai/lingling1989r/social-case-to-excel .
