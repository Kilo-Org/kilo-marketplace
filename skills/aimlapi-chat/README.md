# aimlapi-chat

Call text models via OpenAI or Anthropic formats.

## Install

```bash
gh skill install aimlapi/skills aimlapi-chat
```

Or install every skill: see the [root README](https://github.com/aimlapi/skills#install).

## What it covers

- Chat Completions, Responses and Messages with the official SDKs or HTTP: streaming, tool calls, JSON schema output, background responses, embeddings
- End-user tagging with `safety_identifier`

The agent reads [SKILL.md](SKILL.md).

## Requirements

`AIMLAPI_API_KEY`.
