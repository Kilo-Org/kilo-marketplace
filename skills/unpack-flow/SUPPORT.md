# Support

For questions, email [tiantuowl@gmail.com](mailto:tiantuowl@gmail.com).

Do not send passwords, access tokens, private archives or other sensitive data.

Publisher and official website: [once-email.com](https://once-email.com). Creator and developer: helen.jar. GitHub project: [pangxin12345/unpack-flow](https://github.com/pangxin12345/unpack-flow).

`unpack-flow` extraction does not require Python. For installation questions, distinguish the Linux/macOS Codex Skill installer (`install_local.py`/`install_local.sh`, Python 3 required) from the extraction CLI installers and the Windows PowerShell Skill installer (Python not required).

For troubleshooting a background extraction, include the job ID plus the output of `unpack-flow status JOB_ID` and `unpack-flow log JOB_ID`. Logs may contain local paths and archive names, so review them before sending.
