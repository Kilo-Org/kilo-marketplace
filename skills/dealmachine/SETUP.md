# Connect DealMachine

Use the hosted DealMachine MCP server:

```text
https://mcp.dealmachine.com
```

Complete the OAuth sign-in when the client prompts you. The connection uses your DealMachine account and organization permissions.

If the client does not support remote MCP OAuth, install the CLI:

```bash
npm install -g dealmachine
dm login
```

Do not paste an API key into chat or commit it to a repository.
