# aimlapi-models

Pick, price and check AI/ML API models.

## Install

```bash
gh skill install aimlapi/skills aimlapi-models
```

Or install every skill: see the [root README](https://github.com/aimlapi/skills#install).

## What it covers

- Search and filter the live catalogue by endpoint type, modality and capability
- The exact request parameters of one model, from its OpenAPI description
- Prices by `kind` and `per`, so rates on different bases compare
- Deprecations: which ids are retiring, withdrawn or folded into another

The agent reads [SKILL.md](SKILL.md).

## Requirements

`python3` for the script; no API key.
