# Security policy

SEO Delivery Guard is a text-based orchestration Skill. It does not require credentials, browser profiles, analytics identifiers, search-console access, or third-party API keys.

## Safe use

- Grant access only to the project files and external systems required by the current task.
- Treat analysis as read-only unless the user explicitly requests implementation or an external change.
- Never place secrets, private URLs, customer data, mailbox content, tokens, cookies, or credentials in prompts, reports, examples, screenshots, or release artifacts.
- Use authentication and authorization for private content; crawler controls are not access controls.
- Require explicit task authority before submitting URLs, modifying search properties, publishing code, deploying, or changing third-party settings.

## Reporting

Report security concerns privately to tiantuowl@gmail.com. Do not include a live secret or personal data in the report; describe the affected file and risk with the minimum necessary detail.
