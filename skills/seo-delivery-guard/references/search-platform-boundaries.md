# Search-platform boundaries

Use this reference for search engines other than Google, cross-engine consistency, URL notifications, submissions, or dashboard changes.

## One public truth

Use the same real preferred URL, HTTP status, robots intent, sitemap membership, canonical relationship, hreflang graph, structured data, and content-quality decision across targeted search engines. Do not clone pages, create engine-specific doorway pages, manufacture keyword variants, or publish contradictory crawler instructions.

## Notifications and submissions

IndexNow, crawler hints, sitemap pings, URL inspection, recrawl requests, and similar mechanisms notify or request; they do not replace crawlable internal links, sitemaps, quality, access control, or platform reporting.

Submit only real new, materially updated, moved, or removed preferred URLs when the current official platform contract and task authorization allow it. Do not repeatedly submit unchanged URLs or notify private, noindex, redirected, erroneous, parameterized, or low-value URLs.

## Platform state

Record a property as connected, submitted, crawled, indexed, or published only after current verification through an authorized official interface or API. Public crawlability, a local configuration file, or a third-party tool does not prove account connection or platform state.

Treat dashboard changes, review requests, resource deletion, new account authorization, and identity transfer as external writes. Analysis and monitoring remain read-only unless the task explicitly includes those actions.
