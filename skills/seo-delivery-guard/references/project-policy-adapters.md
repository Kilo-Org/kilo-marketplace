# Project policy adapters

Use this reference when a repository has its own instructions, governance documents, CI, release process, or privacy rules.

## Discover the authority chain

Locate only the files needed for the current task:

1. root and nearest project instructions such as `AGENTS.md`;
2. the project's SEO, content, privacy, localization, analytics, advertising, accessibility, testing, and release rule owners;
3. the active task record when the project requires one;
4. the real build, validation, candidate, deployment, and rollback entry points.

Do not scan unrelated history or private records. Do not copy project rules into this Skill. Record links or paths to their owners.

## Adapter output

Before implementation, summarize:

- rules that are mandatory for this change;
- rules that are not applicable and why;
- conflicts between generic SEO advice and project policy;
- required validation environments;
- permitted and prohibited external actions;
- evidence and documentation that completion requires;
- the owners for reusable rules, current work, capabilities, environment state, third-party state, and release evidence.

## Portable defaults

When a project has no formal governance, use conservative defaults:

- serve indexable primary pages successfully and make their main content accessible;
- keep preferred URLs, canonicals, redirects, internal links, sitemaps, and language relationships coherent;
- keep structured data consistent with visible facts;
- protect private content with access control rather than crawler directives;
- do not send sensitive input to analytics, advertising, logs, or third parties;
- validate the changed URL class before release and verify the public result afterward;
- preserve a reversible release path proportional to the risk.
- keep reusable rules in one authoritative owner instead of duplicating them across instructions, reports, task notes, and generated documentation.

These defaults are not permission to redesign a project or publish changes beyond the user's request.
