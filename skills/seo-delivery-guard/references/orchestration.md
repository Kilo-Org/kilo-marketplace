# Capability orchestration

Use this reference when a task needs more than one SEO discipline or when an audit must become delivery work.

## Route by impact

| Impact | Useful capability class |
|---|---|
| Crawlability, status, rendering, canonical, robots | Technical SEO or page analysis |
| Sitemap membership and URL inventory | Sitemap or site-crawl analysis |
| Hreflang and localized equivalents | International SEO analysis |
| JSON-LD and rich-result eligibility | Structured-data validation |
| Main content, originality, sourcing, trust | Content-quality analysis |
| Search intent and page-type mismatch | Search-experience or SERP analysis |
| LCP, INP, CLS, render blocking | Performance analysis |
| Alt text, dimensions, formats, responsive delivery | Image analysis |
| AI-system comprehension and citability | AI-search analysis, bounded by official facts |
| Search performance or index state | Verified first-party search-property data |
| Referring domains and public citations | Backlink analysis |

## Selection rules

1. Start from the actual change, not from a fixed full-audit checklist.
2. Prefer a narrow specialist over a full audit for a narrow request.
3. Reuse fresh, traceable evidence when its URL, environment, date, and scope match.
4. If the user requests a refresh, the page changed materially, or freshness is uncertain, gather new evidence.
5. If a capability is unavailable, continue with the remaining evidence and name the gap. Do not invent results.
6. Keep first-party property data, public-page observations, laboratory measurements, and third-party estimates separate.

## Reconcile findings

Merge duplicates by affected contract, not by wording. Preserve all materially different evidence sources. When recommendations conflict:

1. follow applicable law, security, privacy, and explicit user scope;
2. follow the nearest project instructions and rule owner;
3. follow verified product and production facts;
4. follow current official platform documentation for platform-specific claims;
5. use third-party recommendations only as advice.

Do not select a recommendation merely because more analyzers repeated it.
