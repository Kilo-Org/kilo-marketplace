# Google Search boundaries

Use this reference only when a conclusion or public claim specifically concerns Google Search.

## Authority and freshness

- Check current Google Search Central, Search Console Help, and the relevant official API documentation for changeable claims.
- Treat Search Console UI, Search Console APIs, PageSpeed Insights, CrUX, and analytics as separate products and evidence scopes.
- A third-party tool's command or score does not prove that Google supports the claimed capability.

## Claims

- Do not promise indexing, ranking, traffic, title-link selection, snippets, rich results, AI Overviews, AI Mode visibility, or advertising approval.
- Describe canonical declarations, sitemaps, structured data, and metadata as signals or eligibility mechanisms where appropriate, not commands to Google.
- E-E-A-T is a quality and trust evaluation concept, not a single mechanical ranking score.
- Google does not require a special AI schema, AI-only page, keyword-variant page, or machine-readable file for AI Overviews or AI Mode.

## Access and index control

- `robots.txt` manages cooperative crawling; it is not authentication, privacy protection, or a reliable removal mechanism.
- Protect private resources with authentication and authorization.
- Do not block a URL in robots while expecting a crawler to read a page-level `noindex` directive.

## APIs

- Verify the current official scope before using a Search Console or related API.
- Do not use Google's Indexing API for ordinary pages. Its official eligible page types are narrow and must be rechecked before use.
- Analysis or a user request to improve SEO does not authorize submitting URLs, changing property settings, or modifying an account.

## Trademark-safe wording

SEO Delivery Guard is an independent project. Use Google in informational text only. Do not put Google into the product name, imply certification, partnership, sponsorship, affiliation, or endorsement, or imitate Google's visual identity.
