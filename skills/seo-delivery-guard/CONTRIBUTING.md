# Contributing

Contributions should preserve the portable text-only core, progressive disclosure, project-policy precedence, evidence separation, and external-action boundaries.

Public examples must use synthetic domains such as `https://example.com`, invented page names, and non-sensitive data. Do not include private repositories, internal infrastructure, real analytics exports, customer information, credentials, or unpublished platform evidence.

Keep platform packaging, release credentials, marketplace coordination, policy snapshots, maintenance scripts, and validation evidence outside the public distribution. A new rule belongs in one authoritative file; other documents should link to it instead of copying divergent versions.

Changes must keep the English README and nine localized READMEs aligned in product facts, installation meaning, limitations, publisher identity, and Google non-affiliation statement.
