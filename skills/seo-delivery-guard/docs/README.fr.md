Les audits SEO détectent des problèmes. **SEO Delivery Guard aide un agent de programmation IA à conduire les constats retenus jusqu'à l'implémentation, la revue, la publication et la vérification en production.**

Il ne remplace ni les crawlers, ni les outils de performance, ni l'analyse de contenu, ni les validateurs de données structurées, ni la recherche SERP, ni les données Search Console. Il orchestre les capacités disponibles, applique les règles du projet et sépare les blocages de publication des recommandations facultatives.

## Pourquoi ce Skill existe

- Un canonical correct dans le code peut être erroné dans le site généré.
- Une traduction non relue peut entrer trop tôt dans le sitemap.
- Des données structurées peuvent décrire des faits invisibles pour l'utilisateur.
- Une directive robots peut être confondue avec un contrôle d'accès.
- Une note globale peut masquer un blocage d'indexation ou de confidentialité.
- Un candidat peut réussir alors que la production sert d'autres métadonnées.
- Une version peut être déclarée réussie avant le nouveau crawl du moteur.

## Capacités principales

- Sélectionne le plus petit ensemble d'analyses SEO pertinent pour chaque modification.
- Lit les règles du projet sur le développement, la confidentialité, la localisation, l'analytics, la publicité, les tests et la publication.
- Arbitre les recommandations contradictoires selon un ordre d'autorité explicite.
- Conserve la source, la date, la confiance, la gravité, l'action, le niveau de validation et l'effet d'un retour arrière.
- Maintient les blocages stricts hors des moyennes et scores de santé.
- Compare le contrat visible par les moteurs avant et après la modification.
- Sépare code source, artefact généré, navigateur, HTTP public, laboratoire, données propriétaires et estimations tierces.
- Maintient indexation, classement, trafic, résultats enrichis, publicité et visibilité IA en attente jusqu'à leur vérification.
- Exige une décision explicite entre conserver, améliorer, fusionner, appliquer `noindex` ou supprimer ; un 301 n'est utilisé que vers un véritable équivalent, sinon le statut reste un `404/410` honnête.

## Ce qu'il ne fait pas

- Ce n'est pas un autre crawler ni un audit SEO tout-en-un.
- Il n'impose aucun fournisseur, API, MCP ou Skill complémentaire.
- Il ne soumet pas d'URL, ne modifie pas de propriété, ne publie pas de code et ne déploie pas sans autorisation de la tâche.
- Il ne garantit ni indexation, ni classement, ni trafic, ni résultats enrichis, ni approbation publicitaire, ni citation par une IA.

## Entrées, sorties et limites

Fournissez uniquement l'URL publique, le chemin du dépôt, la modification prévue, le public, l'intention d'indexation, les langues et les preuves assainies nécessaires. N'envoyez ni mot de passe, ni cookie, ni clé privée, ni export analytique complet, ni donnée sensible. La sortie distingue règles, blocages, conseils, inconnues, limites des preuves, actions, niveaux de validation, état de production et résultats externes en attente.

Le Skill refuse la manipulation du classement, l'expérience ou les preuves inventées, les pages satellites, le contenu massif sans valeur, le contournement des accès, l'exposition de données et les fausses certifications. Une page ou un analyseur indisponible reste inconnu et ne peut pas être déclaré conforme.

Chaque page indexable doit répondre à une tâche que la meilleure URL existante ne couvre pas. La traduction automatique et les contrôles de structure ne prouvent pas la qualité linguistique ; chaque version publique requiert une revue factuelle et linguistique.

## Installation

Installez-le depuis une place de marché compatible ou copiez le dossier complet `seo-delivery-guard` dans le répertoire de Skills reconnu par votre agent. Rechargez les Skills ou ouvrez une nouvelle session, puis invoquez :

```text
$seo-delivery-guard
```

Le paquet public ne contient que des instructions textuelles et des métadonnées : aucun exécutable, crawler, secret API ou composant propre à un système d'exploitation.

## Limites de Google Search

Toute conclusion sur Google Search doit reposer sur la documentation officielle actuelle ou sur des données propriétaires vérifiées. Les outils tiers fournissent des indices, mais ne définissent pas les décisions d'indexation, les facteurs de classement, les résultats enrichis ou les fonctions IA de Google.

SEO Delivery Guard est un projet open source indépendant, sans affiliation, certification, parrainage ni approbation de Google.
