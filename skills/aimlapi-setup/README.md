# aimlapi-setup

Connect your coding agent to AI/ML API.

## Install

```bash
gh skill install aimlapi/skills aimlapi-setup
```

Or install every skill: see the [root README](https://github.com/aimlapi/skills#install).

## What it covers

- Detects which agent you run and configures it with the `aimlapi` CLI
- Browser sign-in: the agent never sees, prints or stores your key
- Dry run first, applies only after you confirm, and can undo

The agent reads [SKILL.md](SKILL.md).

## Requirements

Node.js 18+ and npm.
